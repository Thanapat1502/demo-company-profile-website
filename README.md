# Hero Website 🌟  

A full-stack web project designed to showcase **dynamic content management** and a polished **frontend experience**.  
This project is built with **Next.js** and features a custom **Admin Dashboard** where authorized users can edit **text, images, and videos** across multiple sections of the site.  

---

## ✨ Highlights  

- **Dynamic Content Management (Admin System)**  
  - Update texts, images, and videos without touching the code.  
  - Supports multiple page sections (Hero, Products, Services, News, etc.).  
  - Real-time preview and update with instant publishing.  

- **Internationalization (i18n)**  
  - Supports multiple languages (English / Thai).  
  - Content is fully translated and managed via key-value system.  

- **Flexible Hero Section (SSR Ready)**  
  - Hero banners dynamically load from the database.  
  - Supports different media IDs per page (e.g., HOME, ABOUT_MAIN, PRODUCTS_SERVICE).  

- **Scalable Architecture**  
  - Next.js + TailwindCSS + shadcn/ui for a clean and modern frontend.  
  - Supabase backend for database, storage, and API.  
  - Zustand for lightweight state management.  

---

## 🛠️ Tech Stack  

**Frontend:**  
- Next.js (App Router)  
- TailwindCSS  
- shadcn/ui  
- Hero UI  
- next-intl  

**Backend:**  
- Supabase (Postgres + Auth + Storage)  
- Next.js API Routes (custom APIs for Hero, Products, News, etc.)  

**State & Logic:**  
- Zustand for state management  
- SSR / SSG for SEO optimization  
- Cypress for testing
